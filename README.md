# Open Buggy

All of buggypather's open-source projects in one place. **Suggestions, issues and pull requests are welcome** on any of them.

## Android and phones

| Project | What it is |
| --- | --- |
| [open-launcher-an](https://github.com/buggypather/open-launcher-an) | **Open Home Layout:** your Android home screen (apps, folders, widgets, dock, wallpaper, gestures, news feeds, weather places) as one open file, so it moves to a new phone or another launcher. Includes TypeScript and Java libraries. |

## Libraries

| Project | What it is |
| --- | --- |
| [rar5-ts-reader](https://github.com/buggypather/rar5-ts-reader) | Lists what's inside a RAR 5 archive by reading only its headers (fast even for huge or remote files), and extracts files stored without compression. TypeScript, no dependencies, browsers and Node, plus a `rar5ls` command. Handles self-extracting and multi-volume archives. |

## Claude Code and developer tools

| Project | What it is |
| --- | --- |
| [save-me-claude](https://github.com/buggypather/save-me-claude) | A Claude Code plugin that saves every conversation, your requests and every command or file change Claude makes, to dated folders on your computer. |
| [notify-me-claude](https://github.com/buggypather/notify-me-claude) | A Claude Code plugin that shows a desktop notification when Claude starts, needs permission, replies or finishes (Windows, Mac, Linux). |
| [crash-me-claude](https://github.com/buggypather/crash-me-claude) | A Claude Code plugin that notes errors as they happen and makes redacted crash reports from Claude Code and its IDE extension, ready to save or send. |
| [view-me-claude](https://github.com/buggypather/view-me-claude) | A light VS Code panel beside Claude Code: your phones (adb), running agents and builds, plan usage, servers your agents started, and sessions you can bring back. |

## DevDocs: documentation offline

Documentation packs for [DevDocs](https://github.com/buggypather/devdocs/tree/main-custom-docs) (the doc packs version): searchable, readable offline, and updated every week.

| Project | What it is |
| --- | --- |
| [devdocs](https://github.com/buggypather/devdocs/tree/main-custom-docs) | DevDocs with **doc packs**: add any documentation by pasting a repository's address. |
| [devdocs-pack-builder](https://github.com/buggypather/devdocs-pack-builder) | A template that turns Markdown docs from any public GitHub repository into a doc pack. |
| [devdocs-pack-aosp](https://github.com/buggypather/devdocs-pack-aosp) | Android OS (AOSP) documentation: building, porting, testing and securing Android. |
| [devdocs-pack-chromium](https://github.com/buggypather/devdocs-pack-chromium) | Chromium's developer documentation. |
| [devdocs-pack-firebase](https://github.com/buggypather/devdocs-pack-firebase) | The Firebase JavaScript SDK's API reference. |
| [devdocs-pack-firebase-guides](https://github.com/buggypather/devdocs-pack-firebase-guides) | Firebase's guides: Authentication, Firestore, Cloud Functions, Hosting and more. |
| [devdocs-pack-google-cloud](https://github.com/buggypather/devdocs-pack-google-cloud) | Google Cloud's guides for popular products, each as its own doc. |
| [devdocs-pack-example](https://github.com/buggypather/devdocs-pack-example) | A small example pack to copy when making your own. |
